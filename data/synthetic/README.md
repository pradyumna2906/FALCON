# Synthetic Data

This directory contains reproducible synthetic datasets and their documentation.

Each dataset must document its schema, relationships, units, currency, generator version and intended use. Synthetic records must not be derived from real personal financial records.

The Phase 7.4 transaction-classification reference dataset is documented in
[`classification/README.md`](classification/README.md). It is generated from
reviewed fictional templates and covers every first-release taxonomy leaf.
